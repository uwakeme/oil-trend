# 「油势」微信小程序产品与页面设计（评审稿）

- 版本：V0.1
- 日期：2026-11-10
- 当前阶段：功能与交互设计评审，尚未进入小程序编码
- 暂定名称：油势（可在开发前替换）
- 设计目标：让用户在 5 秒内看懂本地当前油价、下一次调价方向，并能方便地设置降价提醒

> 原型中的价格、日期、通知和提醒记录均为演示数据，不代表真实行情或正式调价结论。

## 1. 产品定位

面向关注加油成本的车主，提供「本地油价 + 调价通知 + 降价提醒 + 价格走势 + 国际原油行情」的一站式工具。

首版不扩展加油支付、加油站团购、资讯社区和复杂金融分析，避免偏离“查油价、等降价”的核心需求。

## 2. 核心用户流程

### 流程 A：查询当前油价
打开小程序 → 确认省市 → 查看 92# / 95# / 98# / 0# 价格 → 查看下次调价窗口与预测 → 决定是否设置提醒。

### 流程 B：接收降价提醒
点击“降价提醒” → 选择地区与油品 → 选择“官方降价即提醒”或设置目标价 → 主动订阅微信消息 → 到达条件后收到提醒 → 回到小程序查看油价与通知原文。

### 流程 C：核对调价通知
进入“调价” → 查看下一次调价窗口或历史通知 → 打开通知详情 → 查看各油品变化、执行时间与来源 → 区分正式公告和市场预测。

### 流程 D：观察趋势
进入“走势” → 切换油品与时间范围 → 查看历史调价节点 → 查看阶段涨跌；进入“国际” → 切换 Brent / WTI → 查看行情与单位说明。

## 3. 信息架构

底部设置 5 个一级入口：油价、走势、调价、国际、提醒。

1. **油价**：默认首页，展示当前地区油价、调价窗口、预测、迷你走势与最新通知。
2. **走势**：国内成品油历史价格与调价节点，支持油品和时间范围切换。
3. **调价**：下一次调价窗口、正式通知、历史记录和通知详情。
4. **国际**：Brent、WTI 原油行情与阶段走势，明确美元/桶和行情时间。
5. **提醒**：降价规则、目标价、订阅消息状态与提醒记录。

## 4. 功能清单

| 模块 | 首版功能 | 关键规则 |
| --- | --- | --- |
| 本地油价 | 省市选择；92#、95#、98#、0#；更新时间；较上次调价变化 | 国内油价按地区展示，不使用“全国统一价”误导用户 |
| 调价窗口 | 下一轮窗口、倒计时、预计方向与幅度 | 预测必须标记“非官方”，正式结果以公告为准 |
| 自动通知 | 服务端定时采集、去重、保存原文、解析结果、失败状态 | 小程序前端不直接承担长期定时抓取 |
| 降价提醒 | 官方降价即提醒、目标价、单次降幅门槛、油品与地区 | 用户主动订阅后才能发微信订阅消息，能力边界如实展示 |
| 国内走势 | 油品切换、近 3 月 / 6 月 / 1 年、调价事件、阶段统计 | 官方价格按调价节点呈现，不伪装成连续实时成交价 |
| 国际行情 | Brent / WTI、涨跌幅、周期切换、行情时间 | 标明美元/桶；实时或延时取决于最终数据源 |
| 基础能力 | 数据异常态、空态、加载态、来源说明、反馈入口 | 数据过期或接口失败时明确提示，不展示“假实时” |

## 5. 页面设计说明

### P1 油价首页

**页面任务**：立即回答“现在多少钱、下一轮可能涨还是跌、要不要提醒我”。

- 顶部：地区选择、数据更新时间、设置入口。
- 主价格区：默认 92#，突出每升价格和较上次调价变化；选中的油品进入大卡，其余油品始终按 92# → 95# → 98# → 0# 的固定顺序显示为小卡，不按点击顺序重排。
- 首页联动：切换大卡油品时，预计调价幅度、近 30 天走势及最新调价通知中的油品与变动金额同步更新；调价窗口日期保持不变。
- 调价卡：下一轮窗口、倒计时、预测方向和幅度。
- 快捷操作：设置降价提醒。
- 辅助信息：近 30 天迷你走势、最新调价通知。

### P2 价格走势

**页面任务**：看趋势，也看懂每一次变化对应的调价事件。

- 油品分段切换：92# / 95# / 98# / 0#。
- 时间范围：近 3 月 / 6 月 / 1 年。
- 图表：历史价格折线或阶梯线、起止价、区间高低点。
- 下方：调价事件列表，红色表示上涨，绿色表示下降。

### P3 调价通知

**页面任务**：把“正式结果”与“市场预测”分开，提供可追溯的通知详情。

- 下一次调价窗口卡。
- 自动同步状态与来源入口。
- 筛选：全部 / 正式结果 / 市场预测。
- 通知详情：执行日期、油品调整幅度、当前价格、来源与原文链接。
- 正式通知和预测使用不同标签，不只依赖颜色区分。

### P4 国际油价

**页面任务**：提供简明的原油市场参考，不把它直接等同于国内零售油价。

- Brent / WTI 切换。
- 当前报价、涨跌额、涨跌幅、行情时间。
- 近 1 日 / 1 周 / 1 月图形。
- 固定说明：单位为美元/桶；国际原油与国内成品油价格存在税费、定价周期等差异。
- 数据源若延时，页面必须显示延时时长。

### P5 降价提醒

**页面任务**：用最少步骤建立一条有效的提醒规则。

- 微信订阅消息状态和开启入口。
- 快捷规则：“官方降价就提醒我”。
- 自定义规则：目标价或单次降幅门槛。
- 条件：地区、油品；默认沿用首页选择。
- 规则摘要：用一句自然语言复述，避免用户误解。
- 历史记录：触发时间、条件和结果。

## 6. 数据与提醒机制建议

### 数据采集

服务端定时任务 → 官方来源与行情接口 → 原始内容快照 → 解析与字段校验 → 去重入库 → 更新价格与通知 → 命中提醒规则 → 发送订阅消息。

正式开发前需要单独验证来源可访问性、字段稳定性、更新频率和授权条款；无法自动解析时进入人工核对队列，不能把猜测值发布为正式结果。

### 提醒优先级

1. 官方正式降价：可信度最高，作为默认提醒。
2. 达到用户目标价：按地区和油品匹配。
3. 预测下调：仅作为可选提醒，默认关闭，避免预期落空造成打扰。

### 微信能力边界

降价提醒依赖用户主动订阅微信消息，不能在未授权时无限后台推送。界面需要展示订阅状态，并在授权不足时引导用户补充订阅。用户身份和提醒规则需要云端保存，以便定时任务跨设备执行。

## 8. 本次需要评审的决策

### 决策 A：一级页面数量

- 背景：油价、走势、调价、国际和提醒都属于首版高频功能。
- 影响：收进二级页面能减少底部导航，但会降低国际行情与提醒的可见性。
- 方案：5 个底部入口，或将“国际”收进首页、“提醒”收进个人中心。
- **推荐：保留 5 个入口**，首版功能清晰，用户不必寻找核心能力。

### 决策 B：地区获取方式

- 背景：国内成品油价格存在地区差异，定位并非所有用户都愿意授权。
- 影响：强制定位会增加首屏阻断；默认全国价则不准确。
- 方案：手动选择省市，可稍后补充定位快捷选择。
- **推荐：首次手动选择并记住，定位仅作可选增强**。

### 决策 C：默认提醒策略

- 背景：预测调价存在反转可能，频繁提醒容易打扰。
- 影响：默认预测提醒会增加消息量，也降低可信度。
- 方案：默认只订阅正式降价，预测提醒由用户主动开启。
- **推荐：默认“官方降价即提醒”，预测提醒默认关闭**。

## 9. 视觉方向

采用“能源行情杂志 + 车载仪表”的轻工业风：暖灰纸面底色、深墨绿主卡、琥珀色品牌强调；上涨使用红色，下降使用绿色；大数字使用等宽感字体。卡片保留清晰边界与数据层级，不使用炫技渐变或无关装饰。

## 10. 评审通过后的下一步

确认功能和页面后，再创建原生微信小程序工程；接入云端数据、定时采集与订阅消息；最后进行数据接口验证、微信开发者工具编译、真机提醒链路测试和发布预检。
