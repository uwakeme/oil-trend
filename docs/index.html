界面

五个页面，五个问题

底部 tabBar 的顺序就是信息架构：先查价，再看走势、核对通知，最后去设提醒。

  1. 01 · 油价

    现在多少钱？

    本地 92# 大卡 + 95# / 98# / 0# 固定顺序小卡；切换大卡油品时，价格、走势、通知里的油品和金额一起换。

  2. 02 · 走势

    什么时候变的？

    阶梯线画价格图，下面列出每一次调价节点，近 3 月 / 6 月 / 1 年可切换。

  3. 03 · 调价

    下一轮涨还是跌？

    正式公告和市场预测分成两栏，不只靠颜色区分，预测一律标「非官方」。

  4. 04 · 国际

    大盘怎么走？

    Brent 与 WTI 行情曲线，固定写明单位是美元/桶，行情延时多少分钟照实标出。

  5. 05 · 提醒

    降到我关心的价就叫我

    能写「官方降价就提醒我」，也能设目标价与单次降幅门槛；预测提醒默认关掉。

算法

全国价 + 地区价差

国内成品油价格有两条规矩：调价幅度全国统一，落地零售价按地区定价。所以价格能拆成两层核对。

某地某油品价格 = 全国价（累加所有调价幅度）+ 地区价差（该地区、该油品）

全国价来自调价时间线；地区价差按油品分别存，覆盖 31 个省级行政区。
⚠️ 这一层现在是校验模型，不是线上算法：小程序显示的价格来自采集器抓到的各省发改委最高零售价，这套模型只留在测试夹具里，用来验证地区价差口径。

01 / 全国统一

幅度一样，落地各省定价

发改委每轮调价给的是全国幅度，各省再定自己的最高零售价。所以同一天各省挂牌价不一样，是正常的。

02 / 分油品存

价差必须按油品分开存

各省标号结构不同，98# 相对 92# 的溢价差得远。四个油品共用一套价差，98# 的误差最大能到 0.89 元/升。

03 / 逐省比对

124 个基准值盯着

基准价存各省真实挂牌价，自检时逐省比对 124 个值。算错了会当场对不上，不会悄悄发出去。

04 / 线上口径

展示的价格另有来路

线上价格由采集器定时抓各省挂牌价入库，走势图与价格表都读这一份。本页的模型只用来校验，不参与对外发布。

开始

克隆下来就能跑

前端没有 npm 依赖，也不需要打包步骤；用微信开发者工具打开目录直接编译。

  1. 01 / 克隆

    拿到代码

    $ git clone https://github.com/uwakeme/oil-trend.git cd oil-trend
  2. 02 / 编译

    用开发者工具打开

    微信开发者工具 2.02.2609250 或更新，基础库 3.8.10，打开这个目录直接编译就能跑。

  3. 03 / 后端（必需）

    先起后端

    小程序的一切取数都走后端，不配地址就没有数据 —— 页面会显示失败态，不会编一份假价格给你。

    $ cd server npm install cp .env.example .env npm start

接上自己的后端

后端是 Node 18 + Express + PostgreSQL。改后端地址只动 config/index.js 的 apiBaseUrl 一处，页面与数据层一行不用动。

域名要先进白名单。公众平台的「服务器域名 → request 合法域名」里没配，请求会被直接拦掉，页面就一直显示失败态。
